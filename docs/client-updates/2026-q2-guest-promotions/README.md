# Клиентский пакет: обновления меню и акции

Русскоязычные материалы для встреч и рассылки клиентам.

## Содержимое

| Файл | Назначение |
|------|------------|
| [presentation.html](./presentation.html) | Интерактивная презентация (открыть в браузере) |
| [presentation.md](./presentation.md) | Тот же текст для импорта в Google Slides / Gamma |
| [film/](./film/) | HyperFrames-ролик (~52 с, без звука) |
| [film/out/](./film/out/) | Готовый MP4 после рендера (если собран) |

## Как показать слайды

1. Откройте `presentation.html` двойным кликом или через «Open with Live Server».
2. Управление: стрелки ← →, пробел, клик по левой/правой половине экрана.
3. Для Google Slides: скопируйте блоки из `presentation.md` (каждый «Слайд N») на отдельный слайд; «Заметки» — в speaker notes.

## Как отправить ролик

После успешного рендера файл лежит в `film/out/guest-menu-updates-ru.mp4` (или `film/renders/`).

Его можно слать в WhatsApp / Telegram / email без открытия HyperFrames.

Пересобрать локально:

```bash
cd film
npx hyperframes lint
npx hyperframes check
npx hyperframes render -o out/guest-menu-updates-ru.mp4
```

Нужны установленные зависимости рендера (см. `npx hyperframes doctor`). Голос и музыка в этом ролике не используются.

- Акции в формате Stories на главной
